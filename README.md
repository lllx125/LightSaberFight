# LightSaberFight

A VR game for Meta Quest 3!
- use light saber to block bullets from drones
- use the force to throw astroids to smash drones
- use the force to pull drones over to cut it!

### video demo [here](https://youtu.be/804Ahf_R96k)
### To play it
download `LIght Saber Fight 1.0.apk` to your Meta Quest 3
